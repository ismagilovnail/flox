# FLOX Dev Panel

Локальная панель разработки FLOX: дашборд прогресса и трекер задач. Не часть
продукта — клиенты её не видят, в `apps/` она не попадает. Первые задачи —
находки аудита `docs/audit-product-2026-10-15.md`.

```
make devpanel                 # из корня репозитория
# или
cd tools/devpanel && go run .
```

Открыть: http://127.0.0.1:8099

## Вкладки

- **Дашборд** (`#dashboard`): готовность к платным клиентам (открытые P0),
  плитки «открыто / P0 / закрыто за 7 дней / в работе», график открытых задач
  по дням (всего и P0, 14/30/90 дней), закрытые по неделям, открытые по
  приоритетам и по типу, «что делать дальше», лента последних изменений.
  У графиков есть подсказки при наведении и табличный вид.
- **Задачи** (`#tasks`): статусы, приоритет, фильтры и поиск, заметки,
  история изменений в карточке, добавление задач (код необязателен).
- **Карта продукта** (`#features`): что реализовано, частично, не проверено.

## Данные

- SQLite: `tools/devpanel/data/tracker.db` (в `.gitignore`). Удалите файл,
  чтобы начать заново с исходного списка.
- При пустой базе загружаются `seed/items.json` и `seed/features.json`.
  `go run . -reseed` добавляет недостающие строки сида и ничего не
  перезаписывает.
- Каждая смена статуса, приоритета, серьёзности, названия, области или «что
  сделать» пишется в `item_changes`. Из этой истории дашборд восстанавливает
  состояние доски на конец каждого дня (`stats.go`), отдельной таблицы
  снимков нет.
- Флаги: `-addr` (по умолчанию `127.0.0.1:8099`), `-db`.

## Безопасность

Входа нет, поэтому сервер слушает только loopback и отклоняет запросы с
чужим `Host` (DNS rebinding), cross-origin записи и записи не в JSON. Не
выставляйте его наружу.

## Устройство

Отдельный Go-модуль: SQLite (`modernc.org/sqlite`, без cgo) не попадает в
`apps/go.mod`. Фронтенд — `web/index.html`, `web/app.css`, `web/app.js` без
сборки и без внешних библиотек (графики — SVG), встроены в бинарник.

API:

| Метод | Путь | |
|---|---|---|
| GET | `/api/stats?days=7..180` | дашборд (по умолчанию 30 дней) |
| GET | `/api/items` | все задачи |
| POST | `/api/items` | создать: `title`, `priority`, `severity`, `kind`, необязательно `code` (`ABC-12`), `area`, `fix` |
| PATCH | `/api/items/{id}` | `status`, `priority`, `severity`, `notes`, `title`, `fix`, `area` |
| DELETE | `/api/items/{id}` | удалить |
| GET | `/api/items/{id}/changes` | история задачи |
| GET | `/api/features` | карта продукта |
| PATCH | `/api/features/{id}` | `status` |

Тесты: `cd tools/devpanel && go test ./...` (расчёт статистики и API на
временной SQLite).
